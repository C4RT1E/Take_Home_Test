# Todo Tracker — Frontend Client

Next.js App Router client application for Todo Tracker.

## Tech Stack
- Next.js 15 (App Router)
- React 19
- Tailwind CSS
- Framer Motion
- Lucide React

## Quick Start Commands

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev
```

Application runs on `http://localhost:3000`.

## Configuration
Set `NEXT_PUBLIC_API_URL` in `.env.local` to configure the backend API target URL.
